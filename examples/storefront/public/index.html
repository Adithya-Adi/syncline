A storefront that records itself

Every button below makes a real request. The browser SDK records the page with rrweb and attaches a traceparent to each call; this server continues that trace and exports spans back to Syncline. Open the recording in the dashboard and the click, the request, and the database span underneath it are on one timeline.

Who is this session?

Sent as the session's user id, which is how you find this recording again later. Changing it starts a new recording.
